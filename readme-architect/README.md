# README Architect

A skill for transforming GitHub repositories into professional, technically verified README files.

## Core capabilities

- Repository-aware README generation
- Automatic stack and version detection
- Professional segmented Shields.io badges
- Mermaid architecture diagrams
- Installation and configuration documentation
- API documentation
- Testing and deployment documentation
- README quality scoring
- Final consistency validation
- No-invention policy

## Badge style

The default visual language uses compact segmented badges:

`PYTHON | 3.12+` `FASTAPI | 0.115` `LICENSE | MIT`

Values must always be derived from the repository.

## Philosophy

**Analyse first. Generate second. Validate last.**

The skill should improve presentation without sacrificing technical accuracy.
